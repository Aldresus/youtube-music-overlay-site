YouTube Music Overlay 0.1.1 preview for Windows x64.

Fixes empty playlist discovery when YouTube Music omits the default membership field. The selector only includes playlists with playlist-edit controls; special lists such as Liked Music are excluded.

Download the ZIP, extract the entire folder and run YouTubeMusicOverlay/YouTubeMusicOverlay.exe. Keep all files together. The browser companion is included in the companion folder.
